reTerminal Sticky, with Greek and Chinese translations alongside the Arabic.

## What it does

- **Home screen** — shows today's reading title, sentence/vocab counts, and
  last sync time.
- **Reading mode** — pages through today's reading text, one sentence per
  screen, each with Arabic (large, right-aligned) plus Greek and Chinese
  translations stacked below.
- **Vocab trainer** — swipeable flashcards from today's vocabulary list; tap
  to flip between the Arabic word and its transliteration/Greek/Chinese.
- **Daily sync** — on boot and once every 24h, connects to WiFi and checks a
  configurable URL for new content, caching it to the SD card. Works fully
  offline from SD-loaded content if no WiFi/URL is configured.

## Controls

- **Bottom menu bar** (baked into every screen) — Home / Read / Train tabs,
  always tappable regardless of current mode.
- **Reading mode**: tap the left or right half of the content area to page
  back/forward.
- **Trainer mode**: tap a card to flip it; swipe left/right to move between
  cards.

## Setup

1. Edit `source/src/config.h`: set `WIFI_SSID`, `WIFI_PASSWORD`, and
   `CONTENT_MANIFEST_URL` (or skip WiFi entirely and load a day package onto
   the SD card by hand — see the top-level project README).
2. Complete the driver integration in `README_DRIVERS.md`.
3. `pio run -e sticky -t upload` from `source/`.

The companion content-generation pipeline (renders daily reading text + vocab
to the bitmap format this firmware reads, optionally via a scheduled GitHub
Action calling the Claude API) lives in the parent project's
`content-pipeline/` and `automation/` folders — not part of this firmware
package itself, since the registry only wants the device-side project here.
