# Fonts needed here

Not bundled (binary + licensing housekeeping) — download these free,
open-license (SIL OFL) Google Noto fonts and place them in this folder:

| File expected here | Get it from | Covers |
|---|---|---|
| `NotoNaskhArabic-Regular.ttf` | fonts.google.com/noto/specimen/Noto+Naskh+Arabic | Arabic script, proper contextual shapes |
| `NotoSans-Regular.ttf` | fonts.google.com/noto/specimen/Noto+Sans | Greek + Latin |
| `NotoSansSC-Regular.otf` | fonts.google.com/noto/specimen/Noto+Sans+SC | Simplified Chinese |

`generate_day.py` loads these by exact filename — rename after downloading
if needed.
